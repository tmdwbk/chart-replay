# 차트 리플레이 연습 도구 (개인용)

> **비상업 개인 연습용**입니다. 매매 신호·투자 조언이 아니며 실제 주문 기능이 없습니다.
> 이 저장소와 사이트에는 **차트 데이터가 들어 있지 않습니다.** 각자 아래 방법으로 내 컴퓨터에 받아서 씁니다.

예전에 거래량이 좋았던 알트코인의 **과거 1분봉**을 받아서, 한 봉씩 넘기며 스캘핑 연습을 하는 도구입니다.
무료이고, 받은 기간 안에서는 몇 번이든 다시 돌려볼 수 있습니다.

- 매매 신호·가격 예측·진입 추천 기능은 없습니다.
- **실제 주문 기능은 없습니다.** 화면의 롱/숏/청산 버튼은 연습 기록용 표시일 뿐입니다.
- API 키를 쓰지 않습니다. 공개 데이터(GET)만 받습니다.
- 시각은 모두 **KST(한국 시간)** 입니다.

## 1. 준비 (한 번만)

맥에 Python 3 가 있으면 됩니다. `requests` 하나만 필요합니다.

```bash
python3 -m pip install --user requests
```

차트 그리는 라이브러리(TradingView 오픈소스 lightweight-charts v4.2.3, Apache 2.0)는 `lib/` 에 들어 있어서 인터넷 없이도 화면이 열립니다.

## 2. 종목 받기

### 상장부터 어제까지 전체 (`--all`, 추천)

```bash
cd ~/chart-replay
python3 fetch.py SANDUSDT --all
python3 fetch.py PEPEUSDT.P --all
python3 fetch.py DOGEUSDT --all
python3 fetch.py SOLUSDT --all
python3 fetch.py ETHUSDT --all
python3 fetch.py BORA --all
```

- 달마다 파일 하나(`data/심볼/…csv.gz`, 한 달 ≈ 1MB 압축)로 저장합니다. 화면에서 종목 → 달을 고릅니다.
- **다시 돌리면 이미 받은 지난달은 건너뛰고 새 달·이번 달만** 받습니다. 매달 한 번 돌리면 최신으로 유지됩니다.
- 중간에 끊겨도 같은 명령을 다시 돌리면 이어서 받습니다.

| 종목 | 받는 곳 | 시작 |
|---|---|---|
| 샌드박스 SANDUSDT | 바이낸스 USDT-M 무기한 선물 | 2021-01 |
| 페페 1000PEPEUSDT | 바이낸스 USDT-M 무기한 선물 (1000개 묶음, 가격 1000배. `PEPEUSDT.P` 로 적어도 됨) | 2023-05 |
| 도지 DOGEUSDT | 바이낸스 USDT-M 무기한 선물 | 2020-07 |
| 솔라나 SOLUSDT | 바이낸스 USDT-M 무기한 선물 | 2020-09 |
| 이더리움 ETHUSDT | 바이낸스 USDT-M 무기한 선물 | 2020-01 |
| 보라 KRW-BORA | **업비트 원화 현물 (선물 아님)** | 업비트 상장 때부터 |

- 보라는 바이낸스·게이트·바이비트·OKX·비트겟 어디에도 무기한 선물이 없어서(2026-11 확인) 업비트 원화 현물로 받습니다.
  화면에 '업비트 원화 현물 (선물 아님)'이라고 나오고, 거래가 없던 분은 봉이 비어 있습니다.
- 업비트는 200개씩 거꾸로 넘기며 받아서 오래 걸립니다(한 달 ≈ 220번 호출). 호출 한도를 넘지 않게 천천히 받습니다.
- 바이낸스 일별 파일은 하루 늦게 올라와서 오늘 데이터는 없습니다.

### 매수·매도 체결량

- 바이낸스 종목은 1분봉·1초봉마다 **시장가 매수 체결량**(taker buy)을 함께 저장합니다. 매도 체결량 = 전체 거래량 − 매수 체결량.
- 화면 거래량 막대: **초록 = 매수 체결, 빨강 = 매도 체결**. 마우스를 올리면 매수·매도 체결량과 매수 비율(%)이 나옵니다.
- 이 칸이 없던 예전 파일은 `python3 fetch.py SANDUSDT --all --force` 처럼 다시 받으면 생깁니다. 업비트(보라)는 캔들에 구분이 없어 한 색으로 나옵니다.

### 1초봉: 1분봉이 만들어지는 과정 보기 (바이낸스 선물 종목, 날짜를 골라서)

```bash
python3 fetch.py PEPEUSDT.P 2026-11-08 2026-11-10 --seconds   # 끝 날짜를 빼면 하루만
python3 fetch.py PEPEUSDT.P --seconds --all                   # 상장부터 어제까지 전체 (원본 약 20GB 를 받아 줄임, 1~2시간, 남는 용량 약 2GB)
```

- 바이낸스 선물 **체결 내역**(aggTrades)을 하루씩 받아 1초 단위 시고저종·거래량으로 줄여 `data/심볼/sec/` 에 저장합니다.
- 원본이 커서(페페 하루 15~100MB 압축) 날짜를 골라 받거나 `--all` 로 전체를 받습니다. 줄인 파일은 하루 1~2MB. 날짜 지정은 한 번에 31일까지.
  `--all` 은 이미 받은 날을 건너뛰어서 중간에 끊겨도 다시 돌리면 이어서 받고, 나중에 돌리면 새 날만 추가합니다.
- 화면에서 **넘기는 단위 → '1초씩'** 을 고르면 1분봉이 1초씩 만들어집니다(체결이 없던 초는 건너뜀).
  1초 데이터가 없는 날은 자동으로 1분씩 넘어갑니다. 진입·청산도 그 초의 가격으로 기록됩니다.
- 체결 내역은 하루 늦게 올라와서 어제까지만 됩니다. 업비트 종목(보라)은 지원하지 않습니다.

### 기간을 정해서 받기

```bash
python3 fetch.py SANDUSDT 2024-03-01 2024-03-31
python3 fetch.py PEPEUSDT.P 2024-02-24 2026-01-01 --monthly
```

- 날짜는 KST 기준(시작일 00:00 ~ 끝날 23:59). 여러 달이면 `--monthly` 를 붙여 달마다 나눠 저장하세요.
- 바이낸스 선물에 없는 종목은 자동으로 업비트 원화 현물로 받습니다. `--source upbit` 로 업비트를 고를 수도 있습니다.

## 3. 리플레이 화면 열기

**방법 1 — 공개 사이트에서 (설치 없이 화면만)**

https://tmdwbk.github.io/chart-replay/ 를 열고 위쪽 **[데이터 폴더 열기]** 로 2번에서 받은 `data` 폴더를 고릅니다.
파일은 내 브라우저 안에서만 읽고, 어디로도 보내지 않습니다.

**방법 2 — 내 맥에서**

```bash
cd ~/chart-replay && python3 -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:8765/replay.html 을 엽니다. `data` 폴더를 자동으로 읽습니다. (끝낼 때는 터미널에서 Ctrl+C)

1. **종목 → 달**: 고른 달과 그 앞 달(지난 흐름)을 읽습니다. 리플레이가 달 끝에 가까워지면 **다음 달이 자동으로 이어집니다.**
   (data 폴더 밖 CSV 는 옆의 파일 선택으로 직접 열 수도 있습니다.)
2. **시작 시각(KST)**: 연습을 시작할 시각을 정하고 **[여기서 시작]**. 그 시각 이후의 봉은 숨겨집니다.
3. **봉**: 1분·3분·5분·15분·1시간. 공개된 1분봉까지만 묶어서 그리므로 미래가 새지 않습니다.
4. **넘기는 단위**: '보는 봉 하나'(5분봉이면 5분씩) 또는 '1분씩'(봉이 만들어지는 과정을 보기).

| 키 | 동작 |
|---|---|
| `→` | 한 봉 넘기기 |
| `Shift` + `→` | 10봉 넘기기 |
| `←` | 한 봉 뒤로 |
| `스페이스` | 자동 재생 / 멈춤 (속도는 위에서 고름) |
| `B` / `S` / `X` | 가상 롱 진입 / 가상 숏 진입 / 청산 |

### 가상 연습 계좌 (실제 주문 아님)

- **시작 잔고 1000 USDT** 로 시작합니다. 잔고는 모든 종목이 함께 쓰고 브라우저에 남습니다. [잔고 초기화] 로 다시 시작할 수 있습니다(시작 잔고 금액도 바꿀 수 있음).
- **증거금**(직접 입력 또는 10%·25%·50%·전부) × **레버리지** = 포지션 크기.
- 진입·청산 가격은 **지금 보이는 마지막 1분봉의 종가**입니다.
- 화면에 보이는 것: 평가 잔고, 잔고, 사용 중 증거금, **미실현 손익(USDT·ROE%)**, 시작 대비 손익, 종목별 **실현 손익**과 낸 수수료, 매매마다 손익(USDT)·ROE%.
- 손익 = 포지션 크기 × 가격 변동% − 수수료(진입·청산 각각 포지션 크기 × 편도 수수료, 기본 0.05%).
- 격리 마진처럼 손실이 증거금에 닿으면 **강제 청산**(증거금 + 진입 수수료를 잃음)으로 처리합니다.
  유지증거금은 빼고 계산해서 실제 거래소보다 조금 늦게 청산됩니다. 슬리피지·펀딩비는 반영하지 않습니다.
- **[기록 CSV 저장]** 으로 증거금·포지션 크기·수수료·손익·청산 후 잔고까지 엑셀에서 열 수 있는 CSV 로 받습니다.

## 파일

```
fetch.py       1분봉 받기 (바이낸스 선물 아카이브 / 업비트 공개 API)
replay.html    리플레이 화면
lib/           lightweight-charts (오픈소스 차트)
data/          받은 1분봉 (data/심볼/…csv.gz, 달마다 하나) 와 목록(index.json)
```
