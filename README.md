# 차트게임 (개인용)

> **2026-11-24: 차트 리플레이 화면은 없앴고 차트게임만 남았습니다.** `replay.html`·`index.html` 로 들어와도 차트게임이 열립니다. 아래 리플레이 설명(1~3장)은 예전 기록으로 남겨 둡니다. 차트게임 설명은 [4. 차트게임](#4-차트게임-거래량-많던-때-주요-알트코인-1분봉-연습)을 보세요.

> **비상업 개인 연습용**입니다. 매매 신호·투자 조언이 아니며 실제 주문 기능이 없습니다.
> 이 저장소와 사이트에는 **차트 데이터가 들어 있지 않습니다.** 각자 아래 방법으로 내 컴퓨터에 받아서 씁니다.

예전에 거래량이 좋았던 알트코인의 **과거 1분봉**을 받아서, 한 봉씩 넘기며 스캘핑 연습을 하는 도구입니다.
무료이고, 받은 기간 안에서는 몇 번이든 다시 돌려볼 수 있습니다.

- 매매 신호·가격 예측·진입 추천 기능은 없습니다.
- **실제 주문 기능은 없습니다.** 화면의 롱/숏/청산 버튼은 연습 기록용 표시일 뿐입니다.
- API 키를 쓰지 않습니다. 공개 데이터(GET)만 받습니다.
- 시각은 모두 **KST(한국 시간)** 입니다.

## 1. 준비 (한 번만)

Python 3 가 있으면 됩니다(맥·윈도우). `requests` 하나만 필요합니다.

```bash
python3 -m pip install --user requests
```

차트 그리는 라이브러리(TradingView 오픈소스 lightweight-charts v4.2.3, Apache 2.0)는 `lib/` 에 들어 있어서 인터넷 없이도 화면이 열립니다.

## 2. 종목 받기

### 상장부터 어제까지 전체 (`--all`, 추천)

```bash
cd ~/chart-replay
python3 fetch.py SANDUSDT --all
python3 fetch.py PEPEUSDT.P --all
python3 fetch.py DOGEUSDT --all
python3 fetch.py SOLUSDT --all
python3 fetch.py ETHUSDT --all
python3 fetch.py BORA --all
```

- 달마다 파일 하나(`data/심볼/…csv.gz`, 한 달 ≈ 1MB 압축)로 저장합니다. 화면에서 종목 → 달을 고릅니다.
- **다시 돌리면 이미 받은 지난달은 건너뛰고 새 달·이번 달만** 받습니다. 매달 한 번 돌리면 최신으로 유지됩니다.
- 중간에 끊겨도 같은 명령을 다시 돌리면 이어서 받습니다.

| 종목 | 받는 곳 | 시작 |
|---|---|---|
| 샌드박스 SANDUSDT | 바이낸스 USDT-M 무기한 선물 | 2021-01 |
| 페페 1000PEPEUSDT | 바이낸스 USDT-M 무기한 선물 (1000개 묶음, 가격 1000배. `PEPEUSDT.P` 로 적어도 됨) | 2023-05 |
| 도지 DOGEUSDT | 바이낸스 USDT-M 무기한 선물 | 2020-07 |
| 솔라나 SOLUSDT | 바이낸스 USDT-M 무기한 선물 | 2020-09 |
| 이더리움 ETHUSDT | 바이낸스 USDT-M 무기한 선물 | 2020-01 |
| 보라 KRW-BORA | **업비트 원화 현물 (선물 아님)** | 업비트 상장 때부터 |

- 보라는 바이낸스·게이트·바이비트·OKX·비트겟 어디에도 무기한 선물이 없어서(2026-11 확인) 업비트 원화 현물로 받습니다.
  화면에 '업비트 원화 현물 (선물 아님)'이라고 나오고, 거래가 없던 분은 봉이 비어 있습니다.
- 업비트는 200개씩 거꾸로 넘기며 받아서 오래 걸립니다(한 달 ≈ 220번 호출). 호출 한도를 넘지 않게 천천히 받습니다.
- 바이낸스 일별 파일은 하루 늦게 올라와서 오늘 데이터는 없습니다.

### 매수·매도 체결량

- 바이낸스 종목은 1분봉·1초봉마다 **시장가 매수 체결량**(taker buy)을 함께 저장합니다. 매도 체결량 = 전체 거래량 − 매수 체결량.
- 화면 거래량 막대: **초록 = 매수 체결, 빨강 = 매도 체결**. 마우스를 올리면 매수·매도 체결량과 매수 비율(%)이 나옵니다.
- 이 칸이 없던 예전 파일은 `python3 fetch.py SANDUSDT --all --force` 처럼 다시 받으면 생깁니다. 업비트(보라)는 캔들에 구분이 없어 한 색으로 나옵니다.

### 1초봉: 1분봉이 만들어지는 과정 보기 (바이낸스 선물 종목, 날짜를 골라서)

```bash
python3 fetch.py PEPEUSDT.P 2026-11-08 2026-11-10 --seconds   # 끝 날짜를 빼면 하루만
python3 fetch.py PEPEUSDT.P --seconds --all                   # 상장부터 어제까지 전체 (원본 약 20GB 를 받아 줄임, 1~2시간, 남는 용량 약 2GB)
```

- 바이낸스 선물 **체결 내역**(aggTrades)을 하루씩 받아 1초 단위 시고저종·거래량으로 줄여 `data/심볼/sec/` 에 저장합니다.
- 원본이 커서(페페 하루 15~100MB 압축) 날짜를 골라 받거나 `--all` 로 전체를 받습니다. 줄인 파일은 하루 1~2MB. 날짜 지정은 한 번에 31일까지.
  `--all` 은 이미 받은 날을 건너뛰어서 중간에 끊겨도 다시 돌리면 이어서 받고, 나중에 돌리면 새 날만 추가합니다.
- 화면에서 **넘기는 단위 → '1초씩'** 을 고르면 1분봉이 1초씩 만들어집니다(체결이 없던 초는 건너뜀).
  1초 데이터가 없는 날은 자동으로 1분씩 넘어갑니다. 진입·청산도 그 초의 가격으로 기록됩니다.
- 체결 내역은 하루 늦게 올라와서 어제까지만 됩니다. 업비트 종목(보라)은 지원하지 않습니다.

### 기간을 정해서 받기

```bash
python3 fetch.py SANDUSDT 2024-03-01 2024-03-31
python3 fetch.py PEPEUSDT.P 2024-02-24 2026-01-01 --monthly
```

- 날짜는 KST 기준(시작일 00:00 ~ 끝날 23:59). 여러 달이면 `--monthly` 를 붙여 달마다 나눠 저장하세요.
- 바이낸스 선물에 없는 종목은 자동으로 업비트 원화 현물로 받습니다. `--source upbit` 로 업비트를 고를 수도 있습니다.

## 3. 리플레이 화면 열기

**방법 1 — 공개 사이트에서 (설치 없이 화면만)**

https://tmdwbk.github.io/chart-replay/ 를 열고 위쪽 **[데이터 폴더 열기]** 로 2번에서 받은 `data` 폴더를 고릅니다.

### 가상 연습 계좌 (실제 주문 아님)

- **시작 잔고 1000 USDT** 로 시작합니다. 잔고는 모든 종목이 함께 쓰고 브라우저에 남습니다. [잔고 초기화] 로 다시 시작할 수 있습니다(시작 잔고 금액도 바꿀 수 있음).
- 주문 칸은 거래소 화면과 비슷합니다: **격리 · 레버리지** → **지정가 / 시장가** 탭 → 가격 → 증거금(슬라이더 0~100%) → TP/SL → **매수(롱) / 매도(숏)**.
  - **증거금** × **레버리지** = 포지션 크기. '사용 가능' 금액과 그 금액으로 잡을 수 있는 **최대 수량**이 버튼 아래에 나옵니다.
  - **시장가**: 지금 보이는 마지막 가격에 바로 진입합니다.
  - **지정가**: 가격을 적고(**[현재가]** 를 누르면 지금 가격이 채워짐) 매수/매도를 누르면, 롱은 지금보다 낮게·숏은 높게 걸어 둡니다.
    다음에 공개되는 봉이 그 가격에 닿으면 **그 가격에 진입**하고 재생이 멈춥니다. 차트에 같은 색 **점선**('지정가 대기')으로 나오고, **[대기 주문 취소]** 로 거둘 수 있습니다.
    지금 가격보다 유리한 가격을 적으면(롱인데 더 높게 등) 실제 거래소처럼 바로 지금 가격에 체결됩니다.
- **추가매수(물타기·불타기)**: 포지션이 있을 때 **같은 방향**으로 매수(롱)/매도(숏)을 다시 누르면 포지션에 더해집니다. 시장가·지정가 모두 됩니다.
  - **평단가 = 진입 금액 합 ÷ 수량 합** (수량 = 금액 ÷ 체결가). 예: 0.0048 에 $1,000, 0.0050 에 $2,000 → 평단 ≈ 0.004932.
  - 증거금·포지션 크기·강제 청산가·손익분기 가격·평단선(ROE%)이 모두 합친 포지션 기준으로 다시 계산됩니다.
  - 레버리지·수수료는 거래소처럼 지금 포지션 것을 그대로 씁니다. 반대 방향 주문은 먼저 청산해야 합니다.
  - 포지션이 있으면 버튼 이름이 바뀝니다: 같은 방향은 **'추가 매수 (롱)'·'추가 매도 (숏)'**, 반대 방향은 '· 청산 먼저'(Reduce-Only 체크 때는 '매도로 롱 줄이기' 등).
  - 추가매수 지정가가 대기 중일 때 포지션이 끝나면 그 대기 주문도 같이 취소됩니다(혼자 새 포지션이 되지 않게).
  - 한 봉에 같은 표시가 여러 번 생기면 '부분 ×3' 처럼 하나로 묶어서 보여 줍니다.
  - 차트에 진입마다 화살표('추가 가격')가 찍히고, 포지션·포지션 기록 탭과 CSV 에 '추가매수 N회'와 체결 내역이 남습니다.
- 청산(X)은 지금 보이는 마지막 가격으로 끝냅니다.
- **부분 청산**: 포지션이 있으면 오른쪽에 '부분 청산' 칸이 나옵니다. 줄일 금액을 **증거금 기준(USDT)** 으로 적거나(진입할 때 적는 증거금과 같은 단위) **25% / 50% / 75%** 를 누르고 **[시장가로 이만큼 청산]**(또는 Enter).
  - 예: 증거금 $100 · 10배(크기 $1,000) 포지션에서 50 을 적으면 증거금 $50(크기 $500)만큼 지금 가격에 팔고 증거금 $50 이 남습니다. 누르기 전에 몇 %인지, 크기로는 얼마인지, 실현 손익, 남는 증거금을 미리 보여 줍니다.
  - 평단가는 그대로이고, 증거금·수량은 같은 비율로 줄어듭니다. 그만큼의 손익(수수료 포함)은 바로 잔고에 들어갑니다.
  - 차트 아래 포지션 탭에도 **[50% 청산]** 버튼과 지금까지의 **실현 손익**이 나옵니다.
  - 남은 포지션까지 끝나면 포지션 기록에 한 줄로 남습니다: 손익 = 부분 청산 + 마지막 청산 합계, 청산가 = **평균 청산가**(수량 가중), ROE = 손익 ÷ 가장 컸을 때 증거금. CSV 에 부분 청산 내역도 남습니다.
- **Reduce-Only (포지션 줄이기만 · 지정가 부분 익절)**: 포지션을 늘리지 않고 줄이기만 하는 주문입니다.
  - 방법 1: 주문 칸에서 **Reduce-Only** 에 체크하면 '증거금' 칸이 **'줄일 증거금 (USDT)'** 으로 바뀝니다(슬라이더 = 지금 증거금의 %, 옆에 크기로 얼마인지 표시).
    지정가 탭에서 가격을 적고 **반대 방향 버튼**(롱이면 [매도 (숏)], 숏이면 [매수 (롱)])을 누르면 걸립니다. 같은 방향을 누르면 막힙니다. 시장가 탭이면 바로 그만큼 청산합니다.
  - 방법 2: 오른쪽 '부분 청산' 칸에 금액과 **지정가**를 적고 **[지정가로 걸기 (부분 익절)]**.
  - 롱은 지금 가격보다 **위**, 숏은 **아래**에만 걸립니다. 지금 가격이거나 반대쪽 가격을 적으면 시장가로 바꾸지 않고 안내만 합니다(바로 줄이려면 [시장가로 이만큼 청산]). 지정가 칸에 '이 값보다 위: 지금 가격'이 흐리게 나옵니다. 여러 개를 다른 가격에 나눠 걸 수 있습니다.
  - 부분 청산 칸에서 금액을 적고 Enter 를 누르면 지정가 칸으로 넘어가고(바로 팔지 않음), 지정가 칸에서 Enter 를 누르면 지정가로 걸립니다.
  - 차트에 **노란 점선**('부분 청산 $금액')으로 나오고, 다른 주문선처럼 **끌어서 옮기거나 ✕ 로 취소**할 수 있습니다. 끄는 동안 그 가격에서의 실현 손익이 나옵니다.
  - 봉이 닿으면 그 가격에 그만큼만 청산되고(평단 그대로, 손익은 바로 잔고에) 재생이 멈춥니다. 금액이 남은 크기 이상이면 전부 청산됩니다('지정가 청산').
  - 같은 봉에서는 손절·강제 청산·익절을 먼저 보고, 그다음 Reduce-Only 지정가를 가까운 것부터 체결합니다. 포지션이 끝나면 남은 Reduce-Only 주문은 자동으로 없어집니다.
  - 대기 주문 탭에 'Reduce-Only 예'로 나오고 닿으면 실현될 손익도 보여 줍니다.
- 오른쪽 '자산' 칸: 평가 잔고, 잔고, 사용 중 증거금, 미실현 손익, 시작 대비 손익.
- **차트 아래 칸** (거래소 화면처럼 탭 세 개):
  - **포지션**: 종목·격리·레버리지, 방향, 수량, **미실현 손익(ROE%)**, 진입가, 예상 청산가, **손익분기 가격**(수수료까지 0원이 되는 가격), TP/SL, 현재가, 증거금, [시장가 청산]. 봉을 넘길 때마다 바뀝니다.
  - **포지션 기록**: 끝난 매매마다 방향, 청산 방식(직접 청산·익절·손절·강제청산), 진입·청산 시각과 가격, 수량, 보유 시간, **실현 손익·ROE%**, 수수료.
    방향(전체·롱·숏)·손익(전체·수익·손실)으로 골라 볼 수 있고, 위에 횟수·승률·실현 손익 합계가 나옵니다.
    **[다른 종목 숨기기]** 를 끄면 이 브라우저에서 연습한 다른 종목 기록도 함께 봅니다.
  - **대기 주문**: 걸어 둔 진입 지정가(가격, 수량, 증거금, TP/SL, 지금 가격까지 몇 %)와 [취소].
- 손익 = 포지션 크기 × 가격 변동% − 수수료(진입·청산 각각 포지션 크기 × 편도 수수료, 기본 0.05%. 지정가·시장가 같은 수수료).
- 격리 마진처럼 손실이 증거금에 닿으면 **강제 청산**(증거금 + 진입 수수료를 잃음)으로 처리합니다.
  유지증거금은 빼고 계산해서 실제 거래소보다 조금 늦게 청산됩니다. 슬리피지·펀딩비는 반영하지 않습니다.
- **평단 가로선**: 포지션을 잡으면 차트에 평단이 가로선으로 나옵니다(**롱 = 초록, 숏 = 빨강**). 선 이름에 **지금 들고 있는 증거금과 ROE%(수수료 포함)** 가 나옵니다. 예: `숏 $150.00 (-1.36%)` — 추가매수하면 늘고, 부분 청산하면 줄어듭니다.
- **TP/SL (익절·손절 지정가)**: 주문 칸의 **TP/SL** 에 체크하고 익절가·손절가를 적은 뒤 매수/매도를 누르면 주문과 함께 걸립니다. 한쪽만 적어도 됩니다.
  - **[진입가에서 ± 0.5% / 1% / 2% / 3%]**: 포지션·대기 주문이 있으면 그 진입가 기준으로 두 칸을 채우고, 없으면 주문할 때 진입가 ±% 로 정해집니다.
  - 이미 잡은 포지션이나 대기 주문에는 값을 적고 **[지금 포지션·주문에 적용]**(또는 칸에서 Enter). **[손익절 취소]** 로 거둡니다.
  - 차트에 **익절 = 파랑 점선, 손절 = 보라 점선**으로 나오고, 적은 가격에서 끝나면 손익이 얼마인지(수수료 포함, ROE%) 미리 보여 줍니다.
  - 다음에 공개되는 봉의 고가·저가가 닿으면 체결됩니다. 익절은 적은 가격 그대로, 손절은 봉이 이미 그 가격을 넘어서 시작했으면 그 봉의 시가로 체결됩니다.
    지정가로 진입한 봉에서는 손익절을 보지 않고 다음 봉부터 봅니다.
  - 한 봉 안에서 익절가와 손절가에 모두 닿으면 어느 쪽이 먼저인지 알 수 없어 **손절로** 처리합니다. 1초씩 넘기면 이런 경우가 줄어듭니다.
  - 체결되면 재생이 멈추고, 매매 기록에 '익절'·'손절'로 표시됩니다.
- **차트에서 끌어서 옮기기**: 대기 중인 **지정가선**과 **익절·손절선**은 선이나 왼쪽의 표(예: `롱 지정가 0.0047712 ✕`)를 마우스로 위아래로 끌면 가격이 바뀝니다.
  - 표의 **✕** 를 누르면 그 주문(지정가 대기·익절·손절)이 취소됩니다.
  - 손익절이 없으면 표 옆에 **[TP/SL]** 버튼이 나옵니다. 누르면 익절·손절선이 ±1% 에 생기고(레버리지가 높으면 강제 청산가 안쪽으로 줄여서), 끌어서 맞추면 됩니다.
  - 끄는 동안 그 가격에서 끝나면 손익이 얼마인지 오른쪽에 나옵니다. 방향이 맞지 않는 곳(롱 지정가를 지금 가격 위로, 롱 손절선을 지정가 위로 등)에 놓으면 제자리로 돌아갑니다.
  - 열린 포지션의 평단선은 옮길 수 없습니다.
- 포지션 기록 탭의 **[기록 CSV 저장]** 으로 증거금·포지션 크기·수수료·손익·청산 후 잔고까지 엑셀에서 열 수 있는 CSV 로 받습니다.

## 4. 차트게임 (거래량 많던 때 주요 알트코인 1분봉 연습)

거래량이 많았던 때의 주요 알트코인 30개 차트를 랜덤으로 여러 번 돌려 보며 직관을 키우는 연습입니다. 가상 매매이고 실제 주문은 없습니다.

**친구에게 줄 때: 이 순서대로 (윈도우, 파이썬만 깔려 있으면 됨)**

> ⚠️ **공개 링크(tmdwbk.github.io)에서는 차트게임을 할 수 없어요.** 차트 데이터를 다시 나눠 줄 수 없어서 공개 사이트에는 데이터가 없고, [게임 시작] 버튼이 눌리지 않아요. `game.html` 을 더블클릭해서 열어도 같아요. 꼭 아래처럼 **내 컴퓨터에서 켜야** 해요.

1. **ZIP 받기**: https://github.com/tmdwbk/chart-replay/archive/refs/heads/main.zip 을 눌러 받아요. (또는 저장소 페이지 초록색 **[Code] → Download ZIP**)
2. **압축 풀기**: 받은 ZIP 을 마우스 오른쪽 → **[압축 풀기] / [모두 압축 풀기]**. ZIP 안에서 바로 실행하면 안 돼요.
3. **실행**: 풀린 폴더(`chart-replay-main`)에서 **`START-CHART-GAME.bat`** 을 더블클릭해요. (맥은 `start_game.command`)
   - 파란 **"Windows의 PC 보호"** 창 → **[추가 정보] → [실행]**.
   - 실행 버튼이 아예 없으면: 파일 마우스 오른쪽 → **[속성]** → 아래 **[차단 해제]** 체크 → [확인] 뒤 다시 더블클릭.
4. **까만 창이 알아서 해요** (처음 한 번만 몇 분):
   - `[1/4]` 준비물 설치 → `[2/4] 새 버전 확인`: **"지금 업데이트할까요? [Y/n]"** 이 나오면 **Enter** (최신 기능으로 맞춤)
   - `[3/4]` 차트 데이터 받기(1분봉 약 200MB, 처음 몇 분~십여 분) → `[4/4]` 브라우저가 열려요.
5. 브라우저에서 **[게임 시작]**. 까만 창은 게임하는 동안 **켜 두고**, 다 하면 닫아요.

**다음부터·업데이트 받기**: 3번(더블클릭)만 하면 돼요. 새 버전이 나와 있으면 까만 창이 물어보고, Enter 를 누르면 **코드만 바꾸고 차트 데이터와 게임 기록은 그대로** 둬요. ZIP 을 다시 받을 필요가 없어요.
(게임 기록·잔고·티어는 브라우저 안에 저장돼서, 같은 브라우저로 열면 이어져요.)

**예전에 ZIP 을 받아 둔 친구** (2026-11-20 이전 버전): 위 1~3번을 한 번만 새로 하세요. 예전 폴더의 `data` 폴더를 새 폴더에 복사해 넣으면 데이터 받기를 건너뛰어요.

**막혔을 때**
| 증상 | 해결 |
|---|---|
| [게임 시작] 이 회색이고 "공개 링크에는 데이터가 없어요" | 공개 링크로 연 거예요. 위 1~3번으로 내 컴퓨터에서 켜요. |

| `Python was not found; run without arguments to install from the Microsoft Store` | 진짜 파이썬이 아니라 윈도우의 바로가기예요. python.org 에서 설치(PATH 체크)하거나, 설정 → 앱 → 고급 앱 설정 → **앱 실행 별칭**에서 python.exe·python3.exe 를 끄고 다시 실행. |
| 데이터 받기 중 멈추거나 실패 | 인터넷 확인 뒤 다시 더블클릭. 받은 달은 건너뛰고 이어 받아요. |

| 업데이트했는데 화면이 그대로 | 브라우저에서 **Ctrl + Shift + R** (맥 ⌘⇧R). |
| 까만 창을 닫았더니 게임이 안 됨 | 정상이에요. 게임하는 동안은 켜 둬야 해요. 다시 더블클릭. |

**명령으로 직접 켜기** (개발용)
