# 차트분석 영상 자동 편집기 (studio)

목소리 없이 녹화한 **차트 화면 영상**과 직접 쓴 **대본**을 넣으면,
채널 브랜딩대로 아래 작업을 자동으로 해서 완성 영상을 만듭니다.

| 기능 | 하는 일 |
|---|---|
| TTS 내레이션 | 대본을 Edge TTS 한국어 목소리로 읽음 (무료, 키 없음) |
| 컷편집 | 구간마다 화면 길이를 내레이션에 맞춤. 길면 최대 2배속까지 빨리 돌리고 남는 뒷부분은 잘라냄, 짧으면 마지막 장면을 멈춰서 늘림. `[컷]` 구간은 삭제 |
| 자막 | 말하는 타이밍에 맞춘 자막. `*단어*` 는 강조색, `[강조]` 줄은 통째로 강조색에 톡 튀어나오는 효과 |
| 하이라이트 | `[줌]` 으로 차트 한 곳 확대, `[하이라이트]` 구간은 `--shorts` 로 세로 쇼츠 자동 생성 |
| 음악 | 배경음악을 깔고 말할 때는 자동으로 볼륨을 줄임(덕킹), 끝에서 페이드아웃. 음량은 유튜브 기준(-14 LUFS)으로 맞춤 |
| 효과음 | `[강조]`, `[챕터]` 에 자동 효과음 + `[효과음:이름]` 으로 원하는 곳에. 기본 내장음: pop, whoosh, ding |
| 브랜딩 | 로고 워터마크, 채널 색·폰트, 제목 카드, 챕터 라벨, 진행바, 면책 문구, 인트로/아웃트로 |
| 업로드용 파일 | `.srt` 자막 파일, 유튜브 챕터가 들어간 설명란 텍스트 |

## 1. 준비 (한 번만)

```bash
brew install ffmpeg
python3 -m pip install --user edge-tts pyyaml
```

## 2. 브랜딩 설정 — `studio/brand.yaml`

채널 이름, 색, 폰트, 로고, 목소리, 배경음악, 효과음, 인트로/아웃트로를 여기서 한 번만 정합니다.
로고·음악 파일은 `studio/assets/` 에 넣고 `logo: {file: assets/logo.png}` 처럼 적으면 됩니다.

- 목소리: `ko-KR-InJoonNeural`(남), `ko-KR-SunHiNeural`(여). 빠르기는 `rate: "+10%"` 처럼 조절합니다.
- 배경음악·효과음은 **직접 가진 파일이나 저작권 걱정 없는 음원**만 쓰세요 (유튜브 오디오 보관함 등).

## 3. 대본 쓰기

`studio/example/script.txt` 를 참고하세요. 시간은 **녹화 영상 기준**입니다.

```
제목: 비트코인 4시간봉, 지지선 다시 확인

0:00 [챕터:오늘의 차트] 안녕하세요. 오늘은 비트코인 4시간봉을 같이 보겠습니다.
0:06 지난주 고점인 *6만 8천 달러* 부근이 강한 저항으로 작용했죠.
0:14 [강조] 여기서 거래량이 크게 터집니다.
0:20-0:28 [컷]
0:28 [챕터:지지선 확인] [하이라이트] [줌:80,60] 가격이 *이전 저항선*까지 내려와서 지지를 받는 모습입니다.
0:38 [하이라이트] 손절 기준을 먼저 정해두는 게 중요합니다. [효과음:ding]
0:52 [끝]
```

| 표시 | 뜻 |
|---|---|
| `0:14 내용` | 녹화 0:14 부터 다음 시간까지 화면에 이 내레이션 |
| `0:20-0:28 [컷]` | 이 범위 삭제 |
| `0:14-0:18 내용` | 0:14~0:18 화면만 쓰고 다음 시간까지는 삭제 |
| `[끝]` | 녹화의 이 시점 이후는 안 씀 |
| `*단어*` | 자막에서 강조색 |
| `[강조]` | 줄 전체 강조 + 튀어나오는 효과 + 효과음 |
| `[줌:x,y,배율]` | 화면의 x%, y% 지점을 제자리에 둔 채 확대 (배율 기본 1.4, `[줌]` 만 쓰면 가운데) |
| `[챕터:이름]` | 화면에 챕터 라벨 + 설명란 챕터 |
| `[하이라이트]` | 쇼츠에 들어갈 구간 |
| `[효과음:이름]` | 구간 시작에 효과음 (내장 pop/whoosh/ding 또는 brand.yaml 의 sfx.files) |
| `[원속도]` | 이 구간은 배속·컷 없이 원본 그대로 (차트에 선 긋는 장면 등) |
| 시간 없이 시작하는 줄 | 윗줄 내레이션에 이어 붙임 |

## 4. 만들기

```bash
cd ~/chart-replay
python3 studio/make_video.py ~/Movies/녹화.mov 대본.txt --preview     # 30초 안팎으로 빠르게 확인 (저화질)
python3 studio/make_video.py ~/Movies/녹화.mov 대본.txt --shorts      # 완성본 + 쇼츠
```

결과는 대본과 같은 폴더의 `out/` 에 생깁니다.

- `대본.mp4` 완성 영상 · `대본_쇼츠.mp4` 세로 쇼츠
- `대본.srt` 자막 파일 (유튜브에 따로 올리면 자동번역에도 쓰임)
- `대본_설명.txt` 제목 · 챕터 시간 · 면책 문구 (설명란에 붙여넣기)
- `대본_작업/` 중간 파일. TTS는 여기 저장돼서 대본을 고쳐도 **바뀐 줄만** 다시 만듭니다.

다른 옵션: `--brand 다른채널.yaml`, `--voice ko-KR-SunHiNeural`, `--voice test`(인터넷 없이 점검용 삐- 소리), `--out 폴더`.

## 5. 진행자 SENA

모든 영상의 오른쪽 아래 동그란 화면에 가상 진행자 **SENA**(금발, 아주 흰 피부, 한쪽 눈 안대)가 나와서 설명합니다.

- 입 모양은 TTS 목소리 크기에 맞춰 3단계(다문 입, 반쯤, 크게)로 움직이고, 몇 초마다 눈을 깜빡입니다. 말하는 동안에는 채널색 테두리가 빛납니다.
- 목소리 기본값은 여성 `ko-KR-SunHiNeural` 입니다.
- 그림은 `studio/presenter/sena/` 의 PNG 6장(`mouth0~2.png`, `blink0~2.png`)입니다. 다른 그림(직접 그린 일러스트나 AI로 만든 이미지 등)으로 바꾸려면 같은 이름의 정사각형 PNG 6장을 새 폴더에 넣고 `brand.yaml` 의 `presenter.images` 경로만 바꾸면 됩니다. 기본 그림을 수정하려면 `studio/presenter/sena.svg.js` 를 고친 뒤 다시 실행하세요.
- 끄려면 `presenter: {enabled: false}`.

## 6. 세로 쇼츠 바로 만들기

녹화 영상이 처음부터 세로(9:16)라면 `--brand studio/brand_shorts.yaml` 로 바로 쇼츠를 만듭니다.
제목은 영상 내내 위에 떠 있고, 자막·SENA·면책 문구는 유튜브 쇼츠의 오른쪽 버튼 줄을 피해서 놓입니다.
실제 예시 대본: `studio/example/sol_shorts.txt` (솔라나, 바이낸스 현물 2026-11-15 종가 기준).
